## ✅ Proyecto: Mini To-Do List (React + TypeScript + Bun)

### 📝 Descripción

Crea una aplicación de lista de tareas mínima pero funcional. El objetivo es aplicar los fundamentos de React, TypeScript y manejo de estado con lógica propia.

---

### 🎯 Requisitos funcionales

- [ ]  Permitir al usuario **agregar tareas** con un input.
- [ ]  Mostrar todas las tareas agregadas en una lista.
- [ ]  Permitir al usuario **marcar tareas como completadas** (cambiar estilo visual).
- [ ]  Permitir al usuario **eliminar tareas** individualmente.

---

### 🛠️ Requisitos técnicos

- [ ]  Proyecto creado con **Bun**.
- [ ]  Usar **React + TypeScript**.
- [ ]  Utilizar tipado explícito para las tareas.
- [ ]  Usar estado local con `useState`.
- [ ]  Dividir el proyecto en al menos 2 componentes si lo deseas (`App`, `TareaItem`, etc).
- [ ]  Estilo básico con CSS propio (inline, archivo CSS o Tailwind si se desea).

---

### 🌟 Extras opcionales

- [ ]  Guardar las tareas en `localStorage`.
- [ ]  Modo oscuro.
- [ ]  Botón para eliminar todas las tareas completadas.
- [ ]  Mostrar número total de tareas y cuántas quedan sin completar.
