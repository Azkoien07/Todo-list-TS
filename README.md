# 📝 Mini To-Do List

Una aplicación sencilla de lista de tareas creada con **React**, **TypeScript** y **Vite**, utilizando **Tailwind CSS** para estilos y **Bun** como gestor de paquetes ultrarrápido. Ideal como proyecto base para aprender conceptos clave de JS/TS y estructura moderna con React.

---

## 🚀 Tecnologías utilizadas

- ⚛️ React 19
- 🟦 TypeScript 5
- ⚡ Vite 6
- 🎨 Tailwind CSS 3
- 🧠 ESLint + Type-Checked Rules
- 🐰 Bun (en lugar de npm/yarn)

---
